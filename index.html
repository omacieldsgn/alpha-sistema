Cole aqui as credenciais do seu projeto Supabase e do OAuth do Google. Elas ficam salvas apenas no seu navegador — nunca são enviadas para nenhum lugar além dos serviços originais.

⚠ Sobre segurança Estas credenciais ficam em localStorage do navegador. Para produção real com múltiplos usuários, migre para variáveis de ambiente no servidor. Para uso pessoal do Wagner num único dispositivo, isso é aceitável.

Como funciona
01 Você autoriza pelo popup oficial do Google. Nenhuma senha passa pelo sistema.
02 O sistema lê seus eventos futuros para saber o que já está agendado.
03 Quando propõe uma mudança, um modal mostra exatamente o que vai alterar.
04 Só depois do "Confirmar", a modificação é gravada no Google Agenda.
